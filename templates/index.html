Please Read Below:

Please Note that: These AI models are trained only on Plants data i.e mainly Agricultural Crops. Moreover during training, only on-target and off-target data are used. Hence uncleaved sites will also be treated as off-target while result generation. At current stage it is recommended to use this tool for validating results from other tools. In result on-target is depicted as 1 and off-target is depicted as 0.

CRISPR-Cas9 is a RNA mediated gene and genome editing technology which can be used to modify genome of organism of interest irrespective of its cellular oragnization i.e prokarotic or eukaryotic.
This particular technique used to edit gene has been derived from a bacteria, Streptococcus pyogenes.
                                  This IASRI-CRISPR (i-CRISPR) tool can be used to predict whether a given target DNA sequence is on or off-target for a given sgRNA. This tool is particularly designed for plants specifically agricultural crops. It works on the principle of binary classification using Artificial Intelligence models for backend processing.

This Tool is developed as Master's thesis project at ICAR-IASRI, New Delhi, India
